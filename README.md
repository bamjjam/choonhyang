|---|---|---|---|

| 2 | 흥부전 | 싹트지 않는 박의 비밀 | 완료 |

6~10화의 시나리오와 코드는 준비되어 있으며, 그림 검증을 마친 순서대로 선택 목록에 공개합니다.

별도 설치 없이 브라우저에서 실행합니다. 각 화의 진행과 판관 일기는 기기 안에 저장됩니다.
